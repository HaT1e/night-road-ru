# Перевод игры Vampire: The Masquerade — Night Road

## Как установить
1. Сделайте резервную копию файла `app.asar` в папке с игрой.
2. Распакуйте `app.asar` программой Asar (или 7-Zip с плагином).
3. Замените файлы в папке `deploy/scenes` на файлы из этого репозитория.
4. Запакуйте папку обратно в `app.asar`.

## Примечание
Перевод выполнен с помощью ИИ и протестирован движком ChoiceScript (Quicktest пройден). Если найдете ошибки — создайте Issue.
