# Русификатор для Vampire: The Masquerade — Night Road

Полный русский перевод текстов игры **Vampire: The Masquerade — Night Road**
(разработчик — Choice of Games) на движке ChoiceScript.

Перевод охватывает всю игру: пролог, главы, диалоги, описания предметов,
интерфейс, подсказки и системные сцены.

## Что в репозитории

Все переведённые файлы лежат в папке `deploy/` — она повторяет структуру
внутри `app.asar`:

```
deploy/
├── scenes/              # тексты игры
│   ├── *.txt            # исходный текст сцены ChoiceScript
│   └── *.txt.json       # упакованная версия для движка игры
├── index.html           # обложка, «Горячие клавиши», служебные надписи
├── credits.html         # экран титров
├── sandbox.html         # экран ошибки загрузки
├── alertify.min.js      # всплывающие диалоги («Отмена» и т. п.)
├── mygame.js            # стартовые значения и названия предметов
├── scene.js             # кнопки «Продолжить», «Следующая глава», ошибки загрузки
├── ui.js                # элементы интерфейса
├── util.js              # сообщения о сохранениях
└── chap_*.svg           # карточки глав с переведёнными названиями локаций
```

Файлы, которые не содержат переведённого текста (служебная логика, не
менявшаяся относительно оригинала, а также картинки-иконки без текста), в
репозиторий не входят — их не нужно заменять.

## Установка

1. Перейдите в папку игры (Windows):

   ```
   \Steam\steamapps\common\Vampire The Masquerade Night Road\resources
   ```

2. Скачайте **7-Zip** и плагин **Asar** для него, затем откройте этим
   архиватором файл `app.asar`.
3. Замените файлы внутри архива на файлы из папки `deploy/` этого
   репозитория, сохраняя структуру (`deploy/scenes/`, `deploy/index.html` и
   т. д.).
4. Сохраните архив и запустите игру.

### Совместимость

- Перевод рассчитан на версию, соответствующую файлам `app.asar` этого
  релиза.
- Дополнения **«Узурпаторы и Изгои»** и **«Секреты и Тени»** переведены —
  их тексты уже включены в файлы сцен.
